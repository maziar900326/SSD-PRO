# SSD-PRO Coding Standard

## Rule 1
Each Engine has only one responsibility.

## Rule 2
Each Engine has one public method:
run()

## Rule 3
Helper methods are private.

## Rule 4
Every Engine has its own unit tests.

## Rule 5
Every Engine returns Models, not dictionaries.

## Rule 6
Do not duplicate logic.

## Rule 7
Prefer readability over short code.

## Rule 8
Quality is always more important than speed.
